# Privet Multi-Spec

This directory is the code-derived specification set. [`../SPEC.md`](../SPEC.md) contains the ordered index and maintenance rules.

Each subsystem document contains implemented scope, explicit non-goals, ownership, exact formats, lifecycle rules, security behavior, configuration, tests, known gaps, and cross-references.

The Rust source and checked-in schemas remain the ultimate executable authority. A discrepancy between code and these documents is a defect and must be resolved explicitly; it must not be hidden by assuming an unimplemented legacy behavior.
